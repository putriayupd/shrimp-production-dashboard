# Shrimp Production Dashboard

An interactive Business Intelligence dashboard developed using **Looker Studio** to monitor shrimp seed and broodstock production at the Balai Produksi Induk Udang Unggul dan Kekerangan (BPIU2K), Ministry of Marine Affairs and Fisheries of Indonesia.

---

## Project Overview

Production data are often stored in spreadsheets, making it difficult to monitor operational performance and identify production trends. This project transforms raw production data into an interactive dashboard that enables managers to monitor production performance in real time.

---

## Objectives

- Visualize shrimp production performance.
- Monitor production and distribution activities.
- Support operational decision-making.
- Improve reporting efficiency.

##  Business Problem

Production reporting relied on spreadsheets, making performance monitoring inefficient and limiting the ability to quickly identify production trends.

---

## Solution

Developed an interactive Looker Studio dashboard that consolidates production information into a single reporting platform with dynamic visualizations and filters.

---

## Business Impact

The dashboard enables managers to:

- Monitor production performance.
- Compare production across provinces.
- Track production trends.
- Improve reporting efficiency.
- Support operational planning.
